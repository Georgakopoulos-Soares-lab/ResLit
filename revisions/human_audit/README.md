# ResLit manual audit: comparison with human annotators

This folder holds the human evaluation of ResLit's extraction accuracy, prepared for the Frontiers in Microbiology revision (Reviewer 1, comment 1; Reviewer 2, comment 1).

Two annotators (A and B) read a stratified random sample of **50 papers** without seeing ResLit's output. For each paper, they listed every antimicrobial resistance gene and mutation that the paper's own results report. The scripts here compare those lists with ResLit's records for the same papers. They report ResLit's precision and recall, by evidence tier, and the agreement between the two annotators.

**Headline result (all 50 papers):**

| | Genes | Mutations |
|---|---|---|
| Precision | **0.738** [0.676–0.791] | **0.646** [0.554–0.728] |
| Precision, weighted to the whole database | **0.811** [0.643–0.934] | **0.630** [0.477–0.825] |
| Organism agreement on matched entries | **0.994** [0.966–0.999] | **1.000** [0.934–1.000] |
| Antibiotic agreement on matched entries | **0.949** [0.906–0.973] | **1.000** [0.957–1.000] |
| Recall | **0.611** [0.550–0.668] | **0.332** [0.273–0.396] |

Values in square brackets are 95% confidence intervals: Wilson intervals, except for weighted precision, which uses a stratified bootstrap (Section 5.5).

## 2. How to run

Requires Python 3 with `pandas` and `openpyxl` (tested with Python 3.8.10, pandas 1.4.3, openpyxl 3.1.5).

```bash
./run_all.sh                       # everything
PYTHON=/usr/bin/python3 ./run_all.sh   # with a specific interpreter

# or one at a time
python3 scripts/gene_allele_compare.py --letter A     # or --letter B
python3 scripts/mutation_compare.py   --letter A
python3 scripts/shared_compare.py
python3 scripts/all_papers_compare.py   # also writes field_and_adjudication.xlsx
```

The scripts read `data/` and write to `results/`. Each prints its summary to the console. Running them again with the same inputs gives the same results.

## 3. Study design

- **Sample:** 50 papers drawn at random (seed 2026) within strata. A paper's stratum is the least-supported ResLit tier among its records × entity type, plus a random stratum. Candidate papers are deliberately over-sampled. Each paper has a sampling weight (`selected_papers.tsv`) for the database-wide estimate.
- **Annotators:** 10 papers were read by both annotators (for agreement), 20 only by A and 20 only by B, so each annotator read 30.
- **ResLit records:** 310 for the 50 papers (197 gene, 113 mutation records). Only rows ResLit itself extracted are included (Source Database = Reslit, tiers Confirmed / Supported / Candidate).

| Stratum | Papers (A / B / both) |
|---|---|
| Candidate – gene | 6 / 5 / 2 |
| Candidate – mutation | 5 / 6 / 2 |
| Supported – gene | 2 / 2 / 1 |
| Supported – mutation | 2 / 2 / 1 |
| Confirmed – gene | 1 / 1 / 2 |
| Confirmed – mutation | 2 / 1 / 1 |
| Random | 2 / 3 / 1 |

## 4. Matching rules

Matching is rule-based and always done within a paper.

### Genes (`gene_allele_compare.py`)
- The annotator's `gene` column is compared with ResLit's `allele` column.
- **Missing `bla` prefix** (annotator side, before normalising): a β-lactamase name written without `bla` gets it, in the same way as the ResLit pipeline does (`_BLA_FAMILIES` / `_BLA_RE` in `pipeline/05_harmonised_pipeline/reslit/genes/qwen3_to_csv.py`). So `CTX-M-15` becomes `blaCTX-M-15`, `TEM-1` becomes `blaTEM-1` and `OXA-48` becomes `blaOXA-48`.
  - The family list is the pipeline's (CTX-M, TEM, SHV, OXA, NDM, KPC, VIM, IMP, GES, CMY, DHA, ACT, BEL, LAP, …) plus PSE and CARB, which the pipeline list does not have.
  - The family must be followed by `-`, `_`, a digit, a space or the end of the name, so `carA` and `car(A)` are left unchanged.
  - It also applies to bracketed synonyms: `blaCARB-2 (PSE-1)` matches `blaPSE-1`.
- **Normalisation** (both sides):
  - A trailing variant number is removed: `blaTEM-1B_1` becomes `blaTEM-1B`, `sul2_2` becomes `sul2`.
  - Names are lowercased, and every character that is not a letter or digit is removed (spaces, `()`, `-`, `'`, `_`).
  - So `aac(6')-Ib` becomes `aac6ib` and `Tet(B)` becomes `tetb`.
- **Several ResLit alleles** in one record (`blaCTX-M-15 | blaCTX-M-27`) are split and compared separately.
- **Synonyms:** an annotator name written as `X (Y)`, e.g. `IniA (Rv0342)` or `strB (aph(6)-Id)`, matches on X, on Y or on the full name.
- **Duplicates:** the same gene listed in several organisms counts once per paper.
- **Matching level:** a match needs the normalised names to be identical. There is no prefix or family rule.
  - A family name does not match a specific allele: B's `blaKPC` in 16965699 is an FN, and ResLit's `blaKPC-1` an FP.
  - Two alleles of the same family do not match: A's `blaCARB-2` vs ResLit's `blaCARB-21` in 30986214.
  - A specific allele does not match a family-only ResLit entry: A's `blaPSE-1` vs `blaPSE` in 22876180.
- **Side effect of removing punctuation:** names that differ only in primes or brackets merge. In 35935201, A's `ant(3')-Ia` matched ResLit's `ant(3'')-Ia`, and `tet(AB)` matched `tetA(B)`.

### Mutations (`mutation_compare.py`)
- A mutation is **gene + change**.
- **Gene:** normalised as above. Annotator synonyms count: `dhfr (spr1429)`, `gyrA/parC`, and descriptive words are ignored (`inhA promoter` matches `inhA`).
- **Change:** standard tokens are read from the text.

| Written as | Read as |
|---|---|
| `S83L`, `Ser83Leu`, `p.Ser83Leu`, `Ser83Leu (S83L)` | `S83L` |
| `Gln35*` | `Q35*` |
| `C-15T`, `c.-15C>T`, `−15C>T`, `−15(CtoT)` | `C-15T` |
| `U2500A` | `T2500A` |

- **Protein or nucleotide:** a mutation's key is its protein change if one is given, otherwise its nucleotide change. ResLit records use the same rule.
- **Several changes in one cell** (`Asp87Gly/Asp87Asn`, `V37A, R267S`) give one mutation each.
- **Unparsed changes:** a change with no standard token (`frameshift`, `Asn518 deletion`, `del Ala50–Arg69`) is kept as an "unparsed" mutation. It can only match identical text, so in practice it counts as a miss (FN).

### Counts
- **TP:** a ResLit entry matched by the annotator. **FP:** a ResLit entry not matched. **FN:** an annotator entry not matched.
- **Precision** = TP / ResLit entries. **Recall** = matched annotator entries / annotator entries.

### Shared and pooled analyses (`shared_compare.py`, `all_papers_compare.py`)
- **Units:** within a paper, ResLit, A and B entries are linked whenever they match (ResLit–A, ResLit–B, and A–B by the same rules). Each linked group is one **unit**, i.e. one determinant.
- **Reference:**
  - On shared papers, the reference is the **union** of A and B: a ResLit entry is correct if either annotator listed it.
  - In the pooled analysis, each paper uses its own annotator's list, and the union on shared papers.
- **Weighted precision:** each ResLit entry is weighted by its paper's sampling weight, which estimates precision for the database as a whole.

### Field agreement (`field_adjudication.py`)
Checked for every matched ResLit–annotator pair (TP). On shared papers, a ResLit entry matched by both annotators gives two pairs.
- **Organism:** same genus + species, case-insensitive.
  - Abbreviated genera match (`E. coli` = `Escherichia coli`). Strain, serovar and subspecies words are ignored.
  - An entry can list several organisms; one shared species is enough.
  - A pair where either side has no species-level name (no organism recorded, `Campylobacter spp.`, `soil metagenome`) is *not comparable* and left out of the rate. Genus-level agreement is reported alongside.
- **Antibiotics:** at least one antibiotic or drug class in common.
  - Every name is resolved with the pipeline's own normaliser (`load_antibiotics`, `resolve_antibiotic`, `normalize_antibiotic` in `scripts/pipeline/clean_organism_resistance.py`, with its reference lists). So `rifampin` = `rifampicin`, `carbapenems` = `carbapenem`, and `amoxicillin-clavulanate` = `amoxicillin/clavulanic acid`.
  - Each resolved name also gets its drug class from the class groups in `antibiotics_names_abreviations.txt`. So `ciprofloxacin` agrees with `fluoroquinolones`, and `gentamicin` with `aminoglycosides`.
  - A β-lactam subclass (carbapenems, penicillins, cephalosporins, monobactams, β-lactamase inhibitors) agrees with the general class "β-lactams", but two different subclasses do not agree with each other. `MLS`/`MLSB` covers macrolides, lincosamides and streptogramins.
  - The groups "Other/misc antibiotics", "Combination / multi-drug entries" and "TB-specific drugs" are not used as classes.

When ResLit finds the right determinant, it almost always assigns the right organism and resistance.
- **Organism:** the one disagreement is aadA1 in 22876180. ResLit gives *Acinetobacter*; the annotator gives *Salmonella*, *E. fergusonii* and *P. aeruginosa*.
- **Antibiotics:** the 9 gene disagreements are all against annotator A:
  - floR given fluoroquinolones instead of phenicols, twice (32404021, 35935201).
  - carA given aminoglycosides instead of macrolides/streptogramins (36160259).
  - Four β-lactamases where ResLit and A name different β-lactam subclasses, penicillins vs cephalosporins: blaLAP-2, blaSHV-11, blaSHV-28 and blaACT-25.
  - Two efflux pumps in 24281307 whose substrates are only partly antibiotics.

  The full list is in `field_pairs`.
- **Missing organisms:** ResLit has no organism for many mutation records (28 of 86 pairs).

**Weighted (database-wide) precision with bootstrap CI**

| | Genes | Mutations |
|---|---|---|
| **Weighted precision** | **0.811** [0.643–0.934] | **0.630** [0.477–0.825] |

- **How the CI is computed:** papers are resampled with replacement within their sampling stratum. There are 10,000 replicates (seed 2026), and the CI is the 2.5th–97.5th percentiles.
- **Why the intervals are wide:** a few Confirmed-gene papers carry very large weights (about 1,382 each), so each of them moves the estimate a lot.

### 5.6 Adjudication

`field_and_adjudication.xlsx` → sheet `adjudication` lists every pooled error for review: **347** in total.

| | FP | FN |
|---|---|---|
| Genes | 58 | 102 |
| Mutations | 40 | 147 |

Each row has these columns:
- a stable `adjudication_id`, the PMID and the annotator(s) who read the paper;
- the ResLit entry (for an FP) or the annotator entry or entries (for an FN);
- `near_miss_other_side`, the look-alike names (genes) or same-gene changes (mutations) on the other side;
- empty `category` and `comment` columns.

**Categories** (a dropdown in the sheet):

| Category | Meaning | Counted as a match? |
|---|---|---|
| correct (annotator missed it) | ResLit's entry is right; the annotator did not list it (FP rows) | yes |
| naming/notation variant | Same determinant written differently (`aph(2''-li1)` vs `aph(2'')-Ii1`; inhA `T8A` vs `T-8A`) | yes |
| coordinate variant | Same mutation in another numbering (rpoB S531L *E. coli* = S450L *M. tuberculosis*) | yes |
| review- or citation-derived | Taken from background, cited work or a review, not the paper's own results | no |
| extraction error | ResLit extracted something wrong | no |
| unresolved | Cannot be decided | no |

**How to adjudicate:**
1. Copy `results/field_and_adjudication.xlsx` to `data/adjudication.xlsx`.
2. On its `adjudication` sheet, fill in `category` and `comment`. Don't change `adjudication_id`.
3. Re-run `python3 scripts/all_papers_compare.py` (or `./run_all.sh`).

The script then does the following:
- It carries your categories and comments into the new `adjudication` sheet.
- It recomputes precision (overall and by tier), recall, F1 and weighted precision, counting the three "match" categories as matches. It reports both the **raw** and the **adjudicated** figures (summary, section 3).
- It lists any problems in `adjudication_issues`: an unknown category (counted as unresolved), or a row that is no longer an FP/FN.

A naming or coordinate variant usually shows up twice: as an FP (ResLit's spelling) and as an FN (the annotator's). Mark both rows, so that precision and recall both count it. No rows have been categorised yet, so the adjudicated figures currently equal the raw ones.

## 6. Where the errors come from

### False positives (ResLit entries no annotator listed)
- **Papers the annotator found no determinants in** give **29 of the 58 gene FPs**:
  - 33109179: 14. Annotator A noted that the genes in the text are BLAST hits.
  - 36980322: 12. A review.
  - 40604919: 3. Both annotators found no genotyping; resistance was tested by disk diffusion only.

  Without these papers, gene precision is **0.849** (163/192).
- **Reviews and meta-analyses** that ResLit treats like primary studies. The clearest case is the meta-analysis **38134888**, with 19 Candidate mutation FPs (17 atpE, 1 prpE, 1 rpoB). This paper alone explains most of the low Candidate mutation precision (0.265).
- **Long gene lists.** In 39211793, 9 ResLit genes were not listed by B, among them blaDHA-1, blaDIM-1, QnrB1 and QnrB4.
- **Wrong gene assigned.** In 29110699, ResLit lists `A1401G` under gyrA, but it is an rrs mutation.
- **Formatting issues the rules do not resolve:**
  - inhA `T8A` vs `T-8A` (29110699): the minus sign was lost.
  - `aph(2''-li1)` vs `aph(2'')-Ii1` (38331708): lowercase "l" for capital "I".

### False negatives (determinants ResLit missed)
- ResLit misses most mutations in papers that report many of them:
  - 37692467: 24 missed
  - 34827322: 23 missed, mostly 23S rRNA changes
  - 30783004: 18 missed
  - 40175930: 15 missed
  - 24399879: 12 missed
- For genes, it misses part of long resistance-gene lists:
  - 36000914: 12 missed
  - 32404021: 10 missed
  - 30013375: 10 missed
- 25 of the mutation FNs are **unparsed** changes (frameshifts, named deletions and duplications), which no rule can match.

## 7. Limitations

- **Rule-based matching.** Unusual names or numbering can show up as an FP plus an FN.
  - rpoB is reported in *M. tuberculosis* numbering by A (S450L, H445Y, D435V) and in *E. coli* numbering by B (S531L, H526Y, D516V). In 40175930 these are probably the same mutations, but they count as different.
  - Use the `*_differences_*.xlsx` files for a manual check, and report any change it makes.
- **Gene records are at gene level** in ResLit, with their alleles listed. An annotator's allele matches if it equals one of them.
- **Empty papers.** A paper an annotator left empty counts as "no determinants", so every ResLit record in it is an FP (see Section 6).
- **Small strata.** Tier-level precision rests on few records, especially Supported, so the confidence intervals are wide.
- **Agreement.** κ is uninformative in this design (see Section 5.4). Positive specific agreement is reported instead.
- **Weighted precision** has a bootstrap CI that is wide, because a few papers carry large weights (Section 5.5).
- **Field agreement** is computed only on matched pairs. When either side has no species-level organism, the pair is not comparable for organism, and these pairs are mostly mutation records with no ResLit organism.
- **Adjudication** is done by people who have seen ResLit's output, so it is not blind. Report raw and adjudicated figures side by side.
- **Annotation versions.**
  - `annotator_B.xlsx` was revised on 2026-10-20: entries were added for 24281307 and 38134888, which had first been left empty.
  - 38134888 still carries `Y` in its "No determinant found" column; this does not affect the counts.
